## 📖 О проекте

Веб-приложение **«Внутренняя L1»** создано для автоматизации учета рабочих смен и прозрачного управления расписанием инженеров технической поддержки. 

Сервис решает проблему ручной координации дежурств: объединяет оперативный дашборд реального времени («Кто дежурит прямо сейчас»), интерактивный календарь на месяц/неделю, ролевое разграничение прав и пакетную загрузку графиков из корпоративных Excel-таблиц.

Интерфейс оформлен в красно-белой корпоративной стилистике, поддерживает автоматическую и ручную смену темы (Light/Dark) и адаптирован для экранов любых размеров.

## ✨ Основные возможности

* **📊 Интерактивный календарь смен:**
  * Просмотр расписания с фильтрацией по месяцам, неделям и сотрудникам.
  * Цветовая маркировка типов дежурств: день, ночь, резерв, праздничные дни.
  * Детальная карточка смены с контактами инженера (телефон, рабочий мессенджер).

* **⏱ Виджет «Дежурные сейчас»:**
  * Оперативный блок на главной странице с актуальным списком дежурных на текущую минуту.
  * Таймер до следующей пересменки и контакты ответственного инженера для экстренной связи.

* **🔐 Разграничение прав доступа (RBAC):**
  * **Администратор / Руководитель группы:** управление пользователями, создание/удаление смен, ручные корректировки, массовый импорт графиков.
  * **Сотрудник L1:** просмотр личного и общего расписания, подача заявок на обмен сменами, отметка о заступлении на дежурство.

* **📁 Пакетный импорт из Excel (.xlsx):**
  * Загрузка готового ежемесячного табеля без ручного ввода каждой смены.
  * Автоматическая валидация: выявление пересечений, двойных смен и некорректных логинов.
  * Экспорт утвержденного расписания обратно в `.xlsx`.

* **🎨 Дизайн и эргономика:**
  * Фирменная красно-белая цветовая гамма.
  * Высококонтрастная тёмная тема для снижения нагрузки на глаза при ночных дежурствах.
  * Полностью адаптивная верстка (десктоп, планшеты, смартфоны).

## 🛠 Стек технологий

| Уровень | Технологии | Назначение |
| :--- | :--- | :--- |

| **Целевая ОС** | РЕД ОС 8 (Муром) / Linux | Эксплуатация в сертифицированном контуре |

## 🚀 Быстрый старт

### Вариант 1: Запуск в Docker (Основной)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/duty-calendar-l1.git
   cd duty-calendar-l1
   ```

2. **Подготовьте файл переменных окружения:**
   ```bash
   cp .env.example .env
   ```
   *(При необходимости задайте свой `SECRET_KEY` и сетевые порты внутри `.env`)*

3. **Запустите проект:**
   ```bash
   docker compose up -d --build
   ```

4. **Проверьте запуск:**
   * Веб-интерфейс: `http://localhost:80`
   * Документация API (Swagger UI): `http://localhost:80/docs`

---

### Вариант 2: Локальный запуск для разработки

1. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate       # Linux / macOS
   # venv\Scripts\activate        # Windows
   ```

2. **Установите зависимости:**
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. **Инициализируйте базу данных:**
   ```bash
   python -m app.database.init_db
   ```

4. **Запустите сервер с автоперезагрузкой:**
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
   Сервис откроется по адресу `http://localhost:8000`.

## 📊 Импорт графика из Excel

Чтобы быстро наполнить расписание на месяц:

1. Перейдите под учетной записью администратора в раздел **Управление → Импорт графика**.
2. Скачайте шаблон таблицы `shift_template.xlsx`.
3. Заполните данные по колонкам:
   * **Дата** в формате `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`.
   * **Тип смены:** `День`, `Ночь`, `Сутки`.
   * **Логин / Табельный номер:** идентификатор инженера из базы.
   * **Статус:** `Основной` или `Резерв`.
4. Загрузите готовый файл. Система выполнит предварительный расчет, покажет сводку ошибок (если они есть) и запишет утвержденный график в базу данных.

## 🐧 Развертывание на РЕД ОС 8

Инструкция по установке в операционной системе **РЕД ОС 8**:

1. **Установите пакеты Docker и утилиты:**
   ```bash
   sudo dnf makecache
   sudo dnf install -y docker-ce docker-compose-plugin git
   ```

2. **Включите и запустите сервис Docker:**
   ```bash
   sudo systemctl enable --now docker
   ```

3. **Откройте сетевые порты в межсетевом экране Firewalld:**
   ```bash
   sudo firewall-cmd --permanent --add-service=http
   sudo firewall-cmd --permanent --add-service=https
   sudo firewall-cmd --reload
   ```

4. **Клонируйте проект и запустите контейнеры:**
   ```bash
   sudo git clone https://github.com/your-username/duty-calendar-l1.git /opt/duty-calendar-l1
   cd /opt/duty-calendar-l1
   sudo cp .env.example .env
   sudo docker compose up -d --build
   ```
